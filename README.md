# Микроатлас

Русскоязычный учебный атлас клинически значимых бактерий и антибиотикорезистентности для клинического фармаколога.

**[Открыть сайт](https://rodionnest.github.io/clinical-microbiology-atlas/)**

## Возможности

- 25 видов и комплексов, 42 учебных профиля, 25 антибиотиков.
- Обзорная таблица и матрица, поиск, фильтры по Граму, профилю, препарату и статусу; сортировка по нажатию на любой заголовок (повторный клик меняет направление); CSV со ссылками.
- Карточки с оригинальными схемами морфологии и источником для каждого включённого правила.
- Вторая вкладка: тесты, немедленный разбор, повторение ошибок, фильтрация по теме/Граму/профилям таблицы.
- Последние 20 тренировок хранятся локально в браузере. Нет регистрации, сервера приложения и аналитики.

## Медицинская методология

Это авторская образовательная выборка, **не антибиотикограмма пациента и не средство выбора лечения**. Независимая клиническая валидация приложения не проводилась. Проверка первичных источников: 5 ноября 2026 года.

Обозначения в таблице:

| Код | Смысл |
| --- | --- |
| R₀ | Ожидаемый видовой резистентный фенотип EUCAST; не обязательно доказанный природный механизм |
| S* | Ожидаемая чувствительность; не индивидуальный результат S и не препарат выбора |
| Rₐ | Приобретённая устойчивость в указанном профиле / экспертном правиле |
| ↓ | Влияние механизма или риск; лабораторный R автоматически не присваивается |
| AST | Чувствительность должна определяться тестированием |
| — | Правило для пары в выборку не включено; это не S, R или утверждение об отсутствии breakpoint |

«Видовой профиль» — учебная группа правил без заданного приобретённого механизма; WT не установлен. WT определяется для пары «вид–препарат» и не гарантирует клиническую чувствительность. MSSA не равно WT.

«Особо устойчивые» — учебная группа карбапенемаз, DTR, CRAB и VRE. Неформальный термин «суперрезистентный» не приравнивается к XDR/PDR. Варианты с механизмами не изображаются как реальные изоляты. Для CRAB явно задан учебный пример с R к имипенему и меропенему; это не профиль всех CRAB.

Источники: официальные EUCAST Expected Resistant v1.2 (2023), Expected Susceptible v1.1 (2022), Expert Rules (Enterobacterales 2024, Staphylococcus и Enterococcus 2025), определения S/I/R и WT; IDSA AMR Guidance 2026; Magiorakos et al. (2012). Реестр URL, версии и область применения находятся в `data.js` и в окне «Источники и методология».

Пороговые MIC и дозировки не воспроизводятся. Числовые пороги CLSI из IDSA не смешиваются с EUCAST. Современная EUCAST I — чувствительность при увеличенной экспозиции; историческое понятие non-susceptible нельзя автоматически переносить в R. Необычные результаты требуют подтверждения.

Изображения — авторские SVG-схемы, не микрофотографии; по ним нельзя определять вид или резистентность. Для базовой морфологии используются учебные материалы CDC и глава Structure из Medical Microbiology (NCBI Bookshelf, 1996); для резистентности старый учебник не используется.

## Запуск и проверка

Статический сайт, без сборки и npm-зависимостей. Нужны HTTP-сервер и современный браузер; открытие `index.html` через `file://` не поддерживается из-за ES-модулей.

```sh
python -m http.server 4173 --bind 127.0.0.1
# Открыть http://127.0.0.1:4173/
node --test tests/atlas.test.js
```

Файлы `data.js`, `questions.js` и `core.js` содержат соответственно медицинские правила, вопросы и логику фильтрации/сортировки. Вопросы по клеткам выводятся из тех же данных, что и таблица. Модульные тесты проверяют происхождение правил и критические различия (MRSA, ESBL, VRE, DTR, HLAR), комбинации фильтров и экспорт.

## GitHub Pages

Публикация из ветки `main`, папки `/ (root)`. В репозитории: Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save. `.nojekyll` отключает обработку Jekyll. Все локальные URL относительные, поэтому сайт работает в подпапке репозитория.

## Обновление данных

Перед изменением правила открыть его первичный источник и проверить вид, препарат, оговорки и версию. Указать `source` и `section` у каждой новой клетки. Не превращать отсутствие данных в чувствительность, наличие гена — в полную антибиотикограмму, а неизвестную категорию — в R. После изменений обновить дату проверки, запустить тесты и проверить карточки и вопросы в браузере.

При публикации медицинских дополнений рекомендуется независимая редакторская проверка специалистом. Пользовательские данные и секреты в репозиторий не включаются.
